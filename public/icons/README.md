# Ícones PWA

Os arquivos de ícones neste diretório são placeholders.

## Como gerar ícones reais

Use uma ferramenta como [PWA Asset Generator](https://github.com/elegantapp/pwa-asset-generator) ou [RealFaviconGenerator](https://realfavicongenerator.net/):

```bash
# Usando PWA Asset Generator
npx pwa-asset-generator logo.png ./public/icons --manifest ./public/manifest.json
```

## Tamanhos necessários

- 72x72
- 96x96
- 128x128
- 144x144
- 152x152
- 192x192
- 384x384
- 512x512

## Design recomendado

- Fundo: Gradiente roxo lilás (#B794F6)
- Ícone: Emoji de pílula (💊) ou símbolo de cruz médica
- Formato: PNG com transparência
- Estilo: Minimalista e legível
